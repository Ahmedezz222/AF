# Установка yolka

## Что нужно иметь

| Что | Зачем | Где взять |
|---|---|---|
| Windows 10 или 11 | целевая система | — |
| Python 3.10+ | на нём написана yolka | [python.org/downloads](https://www.python.org/downloads/) |
| Права администратора | одно окно UAC для доступа к живому диску | — |
| Диск с APFS | что читать: маковский диск или бэкап Time Machine | ваш внешний диск |

**Сторонние пакеты не нужны вообще** — yolka работает на чистой стандартной
библиотеке Python. `pip install` чего-либо не требуется. Драйверы (Paragon,
MacDrive и т.п.) тоже не нужны — а если стоят, ничему не мешают.

Для чтения **образа диска** (файл .img/.dd) права администратора не нужны.

## Шаг 1. Поставить Python

1. Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/) (кнопка Download Python 3.x).
2. При установке **обязательно отметьте галочку «Add python.exe to PATH»** — внизу первого экрана.
3. Проверка: откройте терминал (Win+R → `cmd`) и наберите:

```bash
python --version
```

Должно ответить `Python 3.x.x`.

## Шаг 2. Получить yolka

Вариант с git:

```bash
git clone https://github.com/USERNAME/yolka.git
cd yolka
```

Или просто скачайте ZIP с GitHub (зелёная кнопка Code → Download ZIP),
распакуйте и откройте терминал в этой папке.

Можно установить как пакет (появятся команды `yolka` и `yolka-dav`):

```bash
pip install .
```

— но это необязательно: всё работает и так, через `python -m yolka`.

## Шаг 3. Узнать номер диска

Подключите маковский диск по USB и в терминале выполните:

```bash
wmic diskdrive get index,model,size
```

Найдите свой диск по названию (например, `WD My Passport`) и запомните
его Index — например, `1`. Это и есть `PhysicalDrive1`.

## Шаг 4. Запустить сервер чтения (одно окно UAC)

В терминале **от имени администратора** (правый клик на «Терминал» →
«Запуск от имени администратора»):

```bash
python -m yolka.server \\.\PhysicalDrive1
```

Окно оставьте открытым (сервер сам погаснет после 3 часов простоя).
Это единственное место, где нужны права администратора: сервер только
читает диск и отдаёт байты по локальному порту 47831.

## Шаг 5а. Смонтировать диск буквой

В обычном (не администраторском) терминале:

```bash
python -m yolka.dav
```

И во втором терминале:

```bash
net use Y: \\127.0.0.1@8809\DavWWWRoot
```

Готово: в Проводнике появился диск Y: — ходите по бэкапу, открывайте
и копируйте файлы. Диск только для чтения.

Отключить: `net use Y: /delete`.

## Шаг 5б. Или без монтирования — командами

```bash
python -m yolka info
python -m yolka ls /
python -m yolka ls "бэкап/Data/Users/имя/Documents"
python -m yolka extract "бэкап/Data/Users/имя/Documents/проект" "C:\спасено"
```

Пути внутри диска пишутся через `/`, кавычки нужны, если есть пробелы.
Эмодзи и кириллица в путях работают.

## Если что-то не так

**«Служба WebClient не запущена» при net use** — запустите её:
`net start WebClient` (от администратора) и повторите `net use`.

**Большой файл не копируется с диска Y:** — у встроенного WebDAV-клиента
Windows предохранитель: 50 МБ на файл (наследие 2000-х — клиент скачивает
файл целиком во временную папку, и на медленных сетях большие файлы вешали
Проводник; цифру с тех пор не пересматривали).

Способ 1 — поднять лимит до максимума (от администратора, один раз):

```bash
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters" /v FileSizeLimitInBytes /t REG_DWORD /d 4294967295 /f
net stop WebClient
net start WebClient
```

Потолок станет 4 ГБ — это жёсткий предел клиента (лимит хранится как
32-битное число, больше в него не влезает).

Способ 2 — файлы любого размера без правок системы:

```bash
python -m yolka extract "путь/к/большому/файлу" "C:\куда"
```

`extract` читает диск напрямую, мимо WebClient — лимитов нет, и это быстрее.

**«не найден суперблок NXSB»** — указан не тот диск или раздел не APFS.
Проверьте номер диска (шаг 3).

**Файл отказывается читаться со словами про lzvn/lzfse** — файл сжат
редким для пользовательских данных методом; поддержка в планах.

**Том зашифрован FileVault** — пока не поддерживается.
