# 🌲 yolka

**Читатель APFS-дисков для Windows на чистом Python — без драйверов ядра и зависимостей.**

Монтирует диски Apple File System (включая бэкапы Time Machine) как обычную
букву диска в Windows — через встроенный в саму Windows клиент WebDAV.

[Read in English →](README.md)

## История

Коммерческий драйвер APFS отказался открывать папку из бэкапа Time Machine —
споткнулся об эмодзи (`🌲`) в имени: баг обработки суррогатных пар в именах
файлов. Внутри лежал контент-завод для Telegram-канала, который нужно было
спасти. Пришлось прочитать файловую систему напрямую с диска, в обход
драйвера. Ёлочка, которая всё сломала, дала проекту имя.

## Что умеет

- разбирает APFS с сырых байтов: GPT, контрольные точки, омапы, B-деревья;
- находит последнюю валидную контрольную точку (переживает грязное отключение);
- монтирует том буквой диска через штатный WebDAV — Проводник, любые программы;
- командная строка для скриптов: `ls`, `extract`, `info`;
- любые имена файлов: эмодзи, кириллица, суррогатные пары — тот самый баг;
- распаковывает файлы decmpfs/zlib;
- **только чтение по конструкции** — испортить диск не может в принципе.

## Установка

Полная инструкция — в **[INSTALL.ru.md](INSTALL.ru.md)**. Коротко: Windows 10/11,
Python 3.10+, ни одного стороннего пакета — скачал и запустил.

## Как пользоваться

```bash
# 1. одно окно UAC (сырой доступ к диску):
python -m yolka.server \\.\PhysicalDrive1

# 2. обычным пользователем — подключить диском:
python -m yolka.dav
net use Y: \\127.0.0.1@8809\DavWWWRoot

# ...или без монтирования, через команды:
python -m yolka ls "backup/Users/me/Documents"
python -m yolka extract "backup/Users/me/Documents/проект" "C:\спасено"
```

С образом диска права администратора не нужны вовсе:

```bash
python -m yolka --image backup.img ls /
```

## Ограничения

- записи нет и не будет — осознанно;
- FileVault (шифрованные тома) не поддержан;
- сжатие lzvn/lzfse пока не поддержано (у пользовательских файлов редкость);
- читается актуальное состояние тома (выбор снапшота — в планах).
