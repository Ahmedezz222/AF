# 🌲 yolka

Читатель APFS-дисков для Windows. Только чтение — испортить диск не может в принципе.

Родилась из реальной истории: драйвер Paragon APFS отказался открывать папку
`🌲 Workspace` в бэкапе Time Machine — спотыкался об эмодзи в имени. Пришлось
прочитать файловую систему напрямую с диска, в обход драйвера. Ёлочка, которая
всё сломала, дала проекту имя.

## Что умеет

- находит APFS-раздел в GPT автоматически;
- открывает том на последней валидной контрольной точке;
- показывает каталоги (`ls`), извлекает файлы и папки (`extract`);
- работает с образами дисков и с живыми устройствами;
- имена файлов с эмодзи, кириллицей и чем угодно — без проблем;
- распаковывает файлы, сжатые decmpfs/zlib.

## Чего не умеет (пока)

- запись — и не будет: читалка безопасна по определению;
- FileVault (шифрованные тома);
- сжатие lzvn/lzfse (редко встречается у пользовательских файлов);
- снапшоты по выбору — читает только актуальное состояние.

## Как пользоваться

Доступ к живому диску в Windows требует прав администратора. Чтобы не работать
под администратором постоянно, есть маленький сервер чтения: он запускается
с повышением один раз, дальше всё работает обычным пользователем.

```bash
# 1. от администратора (одно окно UAC):
python -m yolka.server \\.\PhysicalDrive1

# 2. в обычной консоли:
python -m yolka info
python -m yolka ls /
python -m yolka ls "backup/Users/lelya/Documents"
python -m yolka extract "backup/Users/lelya/Documents/проект" "C:\восстановлено"
```

С образом диска сервер не нужен:

```bash
python -m yolka --image backup.img ls /
```
